# TedToolkit.ModularPipelines.Build

Platform-neutral building blocks for deterministic .NET clean, format, build,
test, pack, publish-archive, version-stamping, and cross-job artifact-manifest
workflows.

Use `AddBuildPipeline` with explicit roots and named targets. The package does
not contain a GitHub/GitLab client, AI provider, notification implementation,
package-push operation, or repository-release action.
